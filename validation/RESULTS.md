# MIT-BIH 外部验证结果（1.0.0）

数据：MIT-BIH 心律失常数据库 1.0.0（PhysioNet mitdb），48 条记录去掉 4 条起搏记录（102、104、107、217），
共 44 条 × 60 个 30 秒窗口 = 2640 个窗口（2 个窗口因信号太差无法分析）。MLII 导联，360 Hz 重采样到 512 Hz，
直接送入 `analyze()`。复现：`python validation/mitdb_validate.py --data <mitdb 目录> --out results.json`。

要先说明两点差别：

- MIT-BIH 是 24 小时动态心电图（Holter），受试者大多是年长的住院病人，记录时在活动，噪声和基线漂移比静坐记录的 Apple Watch 大得多。
  所以误报率是偏悲观的估计。
- MLII 是导联 II 方向，不是导联 I。节律和 QRS 宽度可以直接比；ST、T 方向、P 波在不同导联本来就不同，
  所以 ST / T / PR / QTc 的提醒**没有逐项真值**，下面只报告出现率，不算准确率。

## 心搏检出

| 指标 | 结果 |
|---|---|
| 灵敏度 | 99.17%（99,475 / 100,307） |
| 阳性预测值 | 99.31%（多检 691 拍） |
| 纯正常窗口的心率误差 | 中位数 0.03 次/分，第 95 百分位 0.41，最大 10.6 |

## 异常搏动（逐拍）

| 真值 | 工具的标注 | 结果 |
|---|---|---|
| 室性早搏（V、E） | 任一异常标注 | 83.9%（5,617 / 6,695） |
| 室性早搏 | 提前·QRS异形 或 形态异常 | 76.3% |
| 室上性早搏（A、a、J、S），非房颤段 | 提前 | 33.2%（815 / 2,452） |
| 正常心搏，非房颤段 | 被标为异常 | 2.25% |
| 正常心搏，房颤段 | 被标为异常 | 13.2%（房颤本身不规则，工具不做房颤判断） |
| 工具标为异常的心搏，非房颤段 | 真值确实不是正常心搏 | 77.0% |

室上性早搏的逐拍灵敏度低，是因为“提前”的门槛定得保守（< 局部参考 × 0.80，且突然缩短），很多只提前一点的房性早搏不达标。
这是有意的取舍：门槛放低，呼吸引起的心率起伏就会被大量误报为早搏。

## QRS 增宽提醒

| 窗口 | QRS ≥ 120 ms 提醒 |
|---|---|
| 左束支阻滞（≥ 90% 心搏标为 L；180 个） | 70.0% |
| 右束支阻滞（≥ 90% 标为 R；179 个） | 39.1% |
| 正常传导（≥ 90% 标为 N；1,343 个） | 1.2%（误报） |

平均心搏 QRS 宽度（四分位）：正常传导 59 / 68 / 78 ms；束支阻滞 109 / 123 / 127 ms。
右束支阻滞在 MLII 上常表现为宽而缓的 S 波，斜率阈值法容易把它的末段漏掉，所以灵敏度低。
在单导联上，“没有 QRS 增宽提醒”不能排除束支阻滞。

## 形态提醒在纯正常窗口里的出现率（848 个，只含 N 标注，没有真值）

ST 抬高 12%，ST 压低 13%，T 波倒置 14%，PR 延长 13%，PR 偏短 4%，QTc 偏长 8% / 明显延长 1%，
QTc 偏短 4% / 明显偏短 3%，QRS 增宽 1%。

这些数字不是误报率。数据库里的“正常心搏”只说明节律和传导正常，不代表 ST、T、PR、QT 正常
（例如 112 号记录有明显的 ST 压低，123 号的 PR 约 210 ms）。人工抽查 12 个窗口：正常传导的窗口里，
测量点（P 起点、QRS 起止、T 峰、T 末）与目视一致；右束支阻滞的窗口里，J 点有时仍落在宽 S 波的中段，
这时报出的“ST 压低”是测量造成的。

## 验证中发现并修正的问题（相对加入形态提醒前的开发版本）

| 问题 | 修正 | 效果 |
|---|---|---|
| T 波比 R 波还高时（113 号），R 峰检测把 T 波当成心搏，整条记录都被报“提前 + 长间歇” | 去掉“距上一拍 < 0.42 s、斜率不到上一拍 1/3、去掉后前后间隔正好一个 RR”的检出 | 多检 1,880 → 691 拍；纯正常窗口的提前提示 9.2% → 4.5%，长间歇 5.7% → 1.4%；心率误差第 95 百分位 6.1 → 0.4 次/分；这条规则没有删掉任何室性早搏（只看斜率的初版删掉了 223、221 号的 32 个，已据此收紧阈值） |
| 宽 QRS（如左束支阻滞）每拍宽度测量不稳，与平均模板比较时大量正常心搏被标“宽出” | 单拍宽度改为与“形态一致心搏的单拍宽度中位数”比较；相关系数在去基线、轻度平滑后的信号上算 | 109 号某窗口的“形态异常”32 拍 → 0 拍 |
| 右束支阻滞宽 S 波的末段没算进 QRS，J 点落在 S 谷，导致假的 ST 压低 | 平均心搏上把紧邻的缓慢首末波算进 QRS | 右束支阻滞的 QRS 增宽提醒 10.6% → 39.1%（正常传导误报 0.9% → 1.2%） |
| 心率快时 TP 段混进上一拍 T 波，ST、T、P 测歪（合成数据心率 130 时出现假的 ST 压低和 T 倒置） | ST、T、QT 改以 PQ 段为基线；P 仍以 TP 段为基线；心率 > 100 不做 PR 提醒 | 合成快心率记录不再出现 ST/T/PR 误报 |
